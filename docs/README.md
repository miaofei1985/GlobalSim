## 🎯 项目概述

GlobalSim 寰宇模拟盘是一个沉浸式 3D 地球交互 × 全球股票模拟交易 × 实时弹幕竞技 × 10 语种无缝切换的虚拟金融沙盒。

### 核心特性

1. **虚拟经济系统**
   - 总量 1 千万亿 GSB
   - 新用户注册送 1 亿
   - 免费转账 + 防刷限频（20 次/日/50 亿上限）

2. **交易机制**
   - 用户强驱动盘口
   - MR-Bot 均值回归（日回归 0.8%~2% 可配）
   - 指数衰减拉回锚定价

3. **3D 地球首页**
   - Three.js + GSAP
   - 国家→交易所→交易大厅三级导航
   - 热力点/柱状图可视化

4. **专业 K 线**
   - TV Lightweight Charts 引擎
   - 11 种周期 + 9 大指标 + 画线工具
   - 复盘模式 + Level 2 盘口

5. **实时弹幕**
   - WebSocket 推送
   - 支持开关/透明度/屏蔽词
   - 与 K 线时间轴对齐

6. **国际化**
   - 10 语种：zh-CN/en/hi/es/ar/bn/pt-BR/ru/ja/fr
   - RTL 布局适配
   - 本地化格式

## 🎯 成功指标

### 用户指标
- 注册转化率 ≥45%
- 首单完成率 ≥60%
- 7 日留存 ≥35%

### 交互指标
- 弹幕日均 ≥5 条/活跃用户
- 广告 CTR ≥2.5%

### 技术指标
- 接口 P95 <200ms
- K 线帧率 ≥55fps
- WS 稳定性 ≥99.5%

### 合规指标
- 模拟声明曝光 100%
- 敏感内容拦截 ≥95%
- 隐私导出 <24h
